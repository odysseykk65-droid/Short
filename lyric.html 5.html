가사를 붙여 넣고 노래 파일을 올리면, 움직이는 배경 위에 가사가 한 줄씩 떠오르는 영상을 만들어 줍니다. 쇼츠(세로)·유튜브(가로)·정사각형 모두 됩니다.

✨제목만 넣고 자동으로 만들기

제목에 어울리는 새 가사를 Claude가 지어 주고, 배경·글꼴·글자 효과까지 골라 바로 영상을 띄웁니다. 기존 노래 가사는 저작권 때문에 가져오지 않고, 제목에 맞춰 새로 짓습니다.

1가사 넣기

빈 줄과 [1절], [후렴]처럼 대괄호로 적은 줄은 화면에 나오지 않습니다. 처음 넣어 둔 가사는 예시로 만든 것입니다.

2노래 파일 (선택)

노래 파일이 없으면 아래 배경음악이 깔립니다.

  1. 칸에 노래 제목을 적고 🔍 유튜브에서 찾기를 누르면 유튜브 검색 화면이 새 창으로 열립니다.
  2. 마음에 드는 영상에서 공유 → 복사(휴대폰은 공유 → 링크 복사)를 누릅니다.
  3. 이 화면으로 돌아와 📋 복사한 주소 붙여넣고 불러오기를 누르면 끝!

유튜브 소리는 화면에서만 들리고, 저장하는 영상 파일에는 들어가지 않습니다. Claude 안에서는 열리지 않고 GitHub Pages 주소에서 쓸 수 있습니다.

소리가 안 들리면: 휴대폰 볼륨을 올리고, 아이폰은 옆면 무음 스위치를 꺼 주세요.
