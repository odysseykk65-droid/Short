AI 동영상 제작 탐색기

영상 제작 도구를 찾고 바로 시작하세요
📘 사용 설명서

처음 오셨나요? 이렇게 사용하세요

AI로 영상을 만들 때 필요한 사이트를 한곳에 모아둔 도구 모음집입니다. 회원가입 없이 바로 쓸 수 있어요.

1
도구 고르기

위쪽 빠른 시작 버튼(예: ✍️ 텍스트로 영상 만들기)을 누르거나, 왼쪽 분야별 폴더를 누르면 해당 도구만 모아 보여줍니다.

2
카드 눌러 설명 보기

가운데 목록의 도구 카드를 누르면 오른쪽에 설명·유용한 작업·공식 주소가 나타납니다.

3
사이트 바로 열기

오른쪽 파란색 ↗ 웹사이트 바로 열기 버튼을 누르면 새 탭에서 해당 서비스가 열립니다.

4
자주 쓰는 도구 저장

카드의 ☆ 별을 누르면 노란 ★로 바뀌고, 왼쪽 즐겨찾기에 모입니다. 한 번 더 누르면 해제됩니다.

🔍 검색과 정렬

  • 검색창: 도구 이름·기능·용도(예: 자막, 더빙, 쇼츠)로 찾습니다. PC에서는 키보드 / 키를 누르면 바로 검색창으로 이동합니다.
  • 추천 순 / 이름순 / 분야순: 목록 오른쪽 위 선택 상자로 정렬 방식을 바꿉니다.
  • 빠른 시작 버튼은 다시 누르면 필터가 풀립니다.

📂 왼쪽 메뉴

  • 모든 도구: 등록된 전체 도구를 봅니다.
  • 즐겨찾기: 별표한 도구만 봅니다.
  • 최근 열어본 도구: ‘바로 열기’로 연 도구가 최근 순으로 최대 12개 남습니다.
  • 분야별 폴더 ＋: 나만의 분야(폴더)를 새로 만듭니다.
  • 추천 도구 목록 복원: 삭제했던 기본 도구를 되살립니다. 직접 추가한 도구와 즐겨찾기는 그대로 유지됩니다.

✏️ 도구 추가·수정·삭제

  • 오른쪽 위 파란색 ＋ 도구 추가 버튼 → 이름, 웹사이트 주소, 분야, 설명 입력 → 저장.
  • 주소 앞에 https://를 빼고 입력해도 자동으로 붙여줍니다. 이미 등록된 주소는 중복 추가되지 않습니다.
  • 오른쪽 상세 화면 아래 이름·정보 수정, 삭제 버튼으로 고치거나 지웁니다.
  • 주소 복사 / 공유 버튼으로 사이트 주소를 카카오톡 등에 보낼 수 있습니다.

💾 백업 (꼭 알아두세요)

  • 즐겨찾기와 추가한 도구는 지금 쓰는 이 브라우저에만 저장됩니다. 다른 휴대폰·PC에서는 보이지 않고, 인터넷 기록(캐시)을 지우면 사라질 수 있습니다.
  • ⬇ 아래 화살표 아이콘(백업 내보내기): 내 목록을 파일로 내려받습니다.
  • ⬆ 위 화살표 아이콘(백업 가져오기): 받아둔 백업 파일을 골라 다른 기기에서 불러옵니다.

📱 휴대폰에서 쓸 때

  • 화면이 좁으면 메뉴·목록·상세가 한 화면씩 나옵니다.
  • 카드를 누르면 상세 화면으로 넘어가고, 위쪽 ‹ 목록으로를 누르면 돌아옵니다.
  • 목록 화면 위쪽 ‹ 메뉴로를 누르면 즐겨찾기·분야별 폴더가 나옵니다.

⚠️ 이용 시 참고

  • 각 도구는 외부 회사의 사이트입니다. 회원가입, 무료 사용 범위, 요금은 사이트마다 다르니 열어서 직접 확인하세요.
